# Telemetry

Per-session token telemetry, generated by `.claude/lib/generate-session-telemetry.sh` at SessionEnd.

## Layout

- `events/<session_id>.jsonl` — one line per tool call. Fields: `timestamp`, `tool_name`, `tokens_in`, `tokens_out`, `target_resource` (when derivable). `tokens_in`/`tokens_out` are **turn-level** (Claude Code does not expose per-tool breakdown), shared across tools in the same assistant turn.
- `sessions/<session_id>.md` — per-session markdown rollup with YAML frontmatter (totals, useful_unit metrics) and a human-readable narrative body (tool counts, top expensive turns, top subagent dispatches).

The canonical cross-install summary lives elsewhere — at `.claude/observations/token-telemetry-<session_id>.json` — written by the same generator at SessionEnd. That observation is `privacy_class: "safe-to-share"` and routes through the standard observation pipeline (workflow-suggester / audit triad / v1.2.0+ manager-optimizer).

## Useful unit

Defined empirically per Phase 45 CORE 12 (usefulness-is-the-floor):

- `useful_units_shipped` = count of git commits with author-date in the session window
- `useful_units_drafted` = count of files in `.claude/captures/` with mtime in the session window
- `tokens_per_useful_unit` = `(total_tokens_in + total_tokens_out) / max(1, shipped + drafted)`

Not a subjective quality score — a measurable proxy. When the floor metric goes UP across sessions, the manager is generating more output per work shipped. When it goes DOWN, throughput improved.

## Privacy

Telemetry files in `events/` and `sessions/` are per-install local data — they're gitignored. The canonical cross-install summary is the observation file in `.claude/observations/token-telemetry-<session_id>.json`, classified `safe-to-share` (aggregate metrics only — no project content). The redaction lib (`.claude/lib/redact-observation.sh`) gates cross-install emission.

## Manual regeneration

If you want to regenerate telemetry for the current session without ending it (e.g. mid-session diagnostic):

```sh
bash .claude/lib/generate-session-telemetry.sh
```

The lib finds the newest JSONL transcript matching `$CLAUDE_PROJECT_DIR` and writes the three artifacts. Re-runs against the same session overwrite the prior artifacts (same `session_id` = same filename).
